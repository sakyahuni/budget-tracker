# Dodo Budget

고정지출 관리 앱입니다. 월 단위·연 단위로 반복되는 고정지출을 등록하고 관리하는 웹앱입니다.
`index.html` 을 브라우저에서 열면 바로 사용할 수 있으며, 데이터는 지정한 JSON 파일(또는 파일 미연결 시 브라우저 `localStorage`)에 저장됩니다. 자세한 내용은 아래 '저장 방식'을 참고하세요.

## 기능
- 항목 등록·수정·삭제·일시중지 (항목명, 분류, 금액, 매월/매년, 결제월·결제일, 메모)
- 요약: 매월 합계, 매년 결제분 합계, 올해 지출 합계, 월 평균, 이번 달 결제 예정액, 다음 결제일
- 연간 달력: 12개월 각각의 결제 항목과 월별 합계 (31일 결제는 말일로 보정)
- 월별 지출 막대 그래프: 연간 달력 탭 위쪽에 12개월 합계를 막대로 보여 주며, 막대는 색으로 나뉘어 쌓입니다. [항목별 | 분류별] 버튼으로 색 구분 기준을 바꿀 수 있고(선택은 브라우저에 기억), 올해 연간 금액이 큰 6개까지 각자 색을 받고 나머지는 회색 '기타'로 묶입니다. 같은 항목은 연도를 넘겨도 같은 색입니다. 막대에 마우스를 올리거나 키보드로 이동하면 해당 월의 금액이 나오고, '표로 보기'에서 월별 값을 표로 확인할 수 있습니다.
- 항목별 비교 탭: 선택한 연도의 항목별 연간 지출을 큰 순서의 가로 막대로 비교합니다. 월 평균과 전체 대비 비중은 마우스를 올리면 나오고, 표 보기도 제공합니다. 연도 이동은 연간 달력과 함께 움직입니다.
- 분류별 연간 지출 비중
- 상시 지출: 생필품·식료품처럼 특정일에 나가지 않는 지출은 결제일을 '상시 (날짜 없음)'으로 지정합니다. 달력에는 날짜 대신 '상시'로 표시되고, '다음 결제'에서는 제외되며, 금액 합계에는 그대로 반영됩니다.
- 지출 기록(건별): 주유비·생필품·식료품처럼 날짜와 금액이 그때그때 달라지는 지출은 '지출 기록' 탭에 날짜·항목명·분류·금액·메모를 한 줄씩 입력합니다. 항목명이 같은 기록은 월별로 합산되어 연간 달력, 월별 막대 그래프, 항목별 비교, 분류별 집계에 '상시' 항목으로 함께 나타납니다. 기록은 고정지출과 같은 JSON 파일(`records` 항목)에 저장되며, JSON 내보내기에도 포함됩니다(CSV는 고정지출만). 기록이 없는 달은 0원으로 계산됩니다.
- 항목별 지출 내역: 목록에서 항목 이름을 누르면 그 항목의 한 해 12개월 지출(월·날짜·금액·구분)이 창으로 열립니다. 월별 금액이 기록된 달은 '기록', 기록이 없는 달은 기본 금액으로 계산한 '기본 금액(추정)', 월별 금액을 쓰지 않는 항목은 '고정 금액'으로 표시하고, 연도 이동 버튼과 연 합계·월 평균을 제공합니다. 지출 기록 탭에서는 항목 이름을 누르면 그 항목의 기록만 전 기간에 걸쳐 모아 봅니다.
- 월별 금액 입력: 가스·수도요금처럼 달마다 금액이 달라지는 항목은 항목 수정 화면의 '월별 금액' 칸에 연도별·월별 실제 금액을 기록합니다. 기록이 없는 달은 기본 금액이 적용되며, 달력·연 환산·분류별 집계에 반영됩니다. 기본 금액을 0원으로 두면 기록이 없는 달은 추정하지 않고 빈 칸(미기록)으로 남으며, 달력·그래프·합계에서도 빠집니다. 기본 금액이 0원보다 크면 기록이 없는 달에 그 금액이 적용됩니다. 목록의 '금액' 칸은 모든 달의 금액이 같은 항목만 그 금액을 보여 주고, 달마다 금액이 다른 항목은 '월별상이'로 표시합니다. 요약의 '매월 고정지출'도 금액이 고정된 항목만 더합니다.
- JSON 내보내기·불러오기(백업), CSV 내보내기

## 저장 방식
- 화면 상단의 **저장 위치**에서 JSON 파일을 지정하면(새 파일 만들기 / 기존 파일 열기) 변경 사항이 그 파일에 자동 기록됩니다. 파일이 원본이고, 브라우저 `localStorage`는 즉시 표시용 캐시입니다.
- 파일을 OneDrive·iCloud Drive 등 동기화 폴더에 두면 백업과 기기 간 공유를 해당 서비스에 맡길 수 있습니다.
- 파일 핸들은 IndexedDB에 보관되어 다음 방문 때 재연결됩니다. 브라우저를 다시 열면 보안상 [접근 허용]을 한 번 눌러야 할 수 있습니다.
- 파일 직접 저장(File System Access API)은 Chrome·Edge 등 지원 브라우저에서만 동작합니다. 미지원 브라우저에서는 JSON 내보내기로 백업하세요.
- 파일 접근 API는 보안 컨텍스트가 필요하므로 `https://` 호스팅이나 `http://localhost` 에서 여는 것을 권장합니다.
  (예: `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속)
