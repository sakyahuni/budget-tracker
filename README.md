# 고정지출 관리

월 단위·연 단위로 반복되는 고정지출을 등록하고 관리하는 웹앱입니다.
`index.html` 을 브라우저에서 열면 바로 사용할 수 있으며, 데이터는 브라우저의 `localStorage` 에만 저장됩니다.

## 기능
- 항목 등록·수정·삭제·일시중지 (항목명, 분류, 금액, 매월/매년, 결제월·결제일, 메모)
- 요약: 매월 합계, 매년 결제분 합계, 연 환산 총액, 월 평균, 이번 달 결제 예정액, 다음 결제일
- 연간 달력: 12개월 각각의 결제 항목과 월별 합계 (31일 결제는 말일로 보정)
- 분류별 연간 지출 비중
- JSON 내보내기·불러오기(백업), CSV 내보내기
