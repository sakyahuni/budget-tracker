# Dodo Budget

고정지출 관리 앱입니다. 월 단위·연 단위로 반복되는 고정지출을 등록하고 관리하는 웹앱입니다.
`index.html` 을 브라우저에서 열면 바로 사용할 수 있으며, 데이터는 지정한 JSON 파일(또는 파일 미연결 시 브라우저 `localStorage`)에 저장됩니다. 자세한 내용은 아래 '저장 방식'을 참고하세요.

## 기능
- 항목 등록·수정·삭제·일시중지 (항목명, 분류, 금액, 매월/매년, 결제월·결제일, 메모)
- 요약: 전월 고정지출(지난달에 나간 고정 항목 합계), 전월 상시지출(지난달 날짜의 상시지출 합계), 연간 고정지출(매년 결제분), 그리고 전년도 전체 합계와 올해 현재까지 합계를 막대로 비교하는 카드. '현재까지'는 1월 1일부터 오늘까지 실제로 지출된 금액이며, 미리 입력해 둔 앞날의 금액은 넣지 않습니다. 1월에는 전월이 지난해 12월입니다.
- 연간 달력: 12개월 각각의 결제 항목과 월별 합계 (31일 결제는 말일로 보정)
- 월별 지출 막대 그래프: 연간 달력 탭 위쪽에 12개월 합계를 막대로 보여 주며, 막대는 색으로 나뉘어 쌓입니다. [항목별 | 분류별] 버튼으로 색 구분 기준을 바꿀 수 있고(선택은 브라우저에 기억), 올해 연간 금액이 큰 6개까지 각자 색을 받고 나머지는 회색 '기타'로 묶입니다. 같은 항목은 연도를 넘겨도 같은 색입니다. 막대에 마우스를 올리거나 키보드로 이동하면 해당 월의 금액이 나오고, '표로 보기'에서 월별 값을 표로 확인할 수 있습니다.
- 항목별 비교 탭: 선택한 연도의 항목별 연간 지출을 큰 순서의 가로 막대로 비교합니다. 월 평균과 전체 대비 비중은 마우스를 올리면 나오고, 표 보기도 제공합니다. 연도 이동은 연간 달력과 함께 움직입니다.
- 분류별 연간 지출 비중
- 상시 지출: 생필품·식료품처럼 특정일에 나가지 않는 지출은 결제일을 '상시 (날짜 없음)'으로 지정합니다. 달력에는 날짜 대신 '상시'로 표시되고, '다음 결제'에서는 제외되며, 금액 합계에는 그대로 반영됩니다.
- 지출 추가: 맨 위 '지출 추가' 카드에서 [상시지출 | 고정지출]을 골라 모든 지출을 한곳에서 입력합니다(열 때마다 상시지출이 먼저 나옵니다). 고정지출은 보험료·통신비·공과금처럼 정해진 주기로 나가는 항목이고, 상시지출은 주유비·생필품·식료품처럼 날짜와 금액이 그때그때 달라지는 지출을 날짜·항목명·분류·금액·메모로 건별 입력합니다. 상시지출은 '상시지출 목록' 탭에서 월별로 조회·수정·삭제하며, 항목명이 같은 건은 월별로 합산되어 연간 달력·월별 막대 그래프·항목별 비교·분류별 집계에 함께 나타납니다. 기록은 고정지출과 같은 JSON 파일(`records` 항목)에 저장되며, 백업 내려받기(JSON)에도 포함됩니다. 기록이 없는 달은 0원으로 계산됩니다.
- 항목별 지출 내역: '고정지출 목록'에서 항목 이름을 누르면 그 항목의 한 해 12개월 지출(월·금액·구분)이 창으로 열립니다. 월별 금액이 기록된 달은 '기록', 기록이 없는 달은 기본 금액으로 계산한 '기본 금액', 월별 금액을 쓰지 않는 항목은 '고정 금액'으로 표시하고, 연도 이동 버튼과 연 합계·월 평균을 제공합니다. '상시지출 목록' 탭에서는 항목 이름을 누르면 그 항목의 내역만 전 기간에 걸쳐 모아 봅니다. 상세 창의 [금액 수정]을 누르면 월별 금액을 그 자리에서 바로 고칠 수 있습니다(요금제 변경·구독 중단 등). 금액을 넣고 Enter를 누르면 다음 달로 넘어가고, ↓ 버튼은 그 달의 금액을 아래 달에 모두 적용하며, 0을 넣으면 그 달은 중단(0원)으로 달력·합계·CSV에서 빠지고, 칸을 비우면 기본 금액(없으면 미기록)으로 돌아갑니다.
- 월별 금액 입력: 가스·수도요금처럼 달마다 금액이 달라지는 항목은 항목 수정 화면의 '월별 금액' 칸에 연도별·월별 실제 금액을 기록합니다. 기록이 없는 달은 기본 금액이 적용되며, 달력·연 환산·분류별 집계에 반영됩니다. 기본 금액을 0원으로 두면 기록이 없는 달은 추정하지 않고 빈 칸(미기록)으로 남으며, 달력·그래프·합계에서도 빠집니다. 기본 금액이 0원보다 크면 기록이 없는 달에 그 금액이 적용됩니다. 목록의 '금액' 칸은 모든 항목(공과금 포함)이 가장 최근에 기록한 금액을 보여 줍니다(요금제 변경·구독 중단이 있어도 최근 금액이며, 중단 중이면 0원). 요약의 '매월 고정지출'도 모든 고정 항목의 최근 기록 금액을 더합니다.
- 백업·가져오기(맨 위 카드): 지금 한 번만 파일을 주고받는 기능이며 파일과 연결되지 않습니다. [백업 내려받기 (JSON)]은 고정지출과 상시지출 전체의 사본을(파일 이름은 `dodo-budget-날짜.json`, 예: `dodo-budget-20261102.json`), [파일에서 가져오기 (JSON)]은 JSON 파일의 내용을 읽어 현재 데이터를 대체하거나(확인) 덧붙입니다(취소).
- 엑셀용 내려받기 (CSV)(파일 이름은 `dodo-budget-날짜.csv`): 엑셀 분석용으로 '한 줄에 한 번의 지출'을 담습니다. 열은 날짜·구분(고정지출/상시지출)·항목·분류·금액·메모이며, 고정지출은 금액이 있는 달마다 한 줄, 상시지출은 건마다 한 줄입니다. 금액 열을 더하면 '올해 지출 합계'와 같고(중지한 항목과 기록 없는 달은 제외), 데이터가 있는 모든 연도를 날짜순으로 담습니다. 가져오기에는 JSON만 쓸 수 있습니다.
- 백업 알림: 매월 1일부터 앱을 열면 상단에 '이번 달 백업을 아직 받지 않았습니다' 배너가 나타나고, [백업 내려받기 (JSON)]을 받거나 [이번 달은 건너뛰기]를 누르면 그 달에는 사라집니다. 앱을 켜 둔 채 달이 바뀌어도 1분 안에 나타납니다. 설정(알림 켜기·끄기)과 마지막 백업 날짜는 이 브라우저에 저장됩니다. 서버가 없는 웹페이지라 앱을 닫아 둔 상태에서는 알릴 수 없으므로, 맨 위 카드의 [캘린더에 매월 1일 알림 추가 (.ics)]로 '매월 1일 오전 9시 반복 일정'을 내려받아 캘린더 앱에 넣으면 앱을 닫아 둬도 알림이 옵니다.

## 저장 방식
- 화면 상단의 **자동 저장**에서 [새 파일 만들어 연결] 또는 [기존 파일 열어 연결]로 JSON 파일을 지정하면 변경 사항이 그 파일에 입력할 때마다 자동으로 기록됩니다. 파일이 원본이고, 브라우저 `localStorage`는 즉시 표시용 캐시입니다. (연결 없이 한 번만 주고받는 것은 위의 '백업·가져오기'입니다.)
- 파일을 OneDrive·iCloud Drive 등 동기화 폴더에 두면 백업과 기기 간 공유를 해당 서비스에 맡길 수 있습니다.
- 파일 핸들은 IndexedDB에 보관되어 다음 방문 때 재연결됩니다. 브라우저를 다시 열면 보안상 [접근 허용]을 한 번 눌러야 할 수 있습니다.
- 파일 직접 저장(File System Access API)은 Chrome·Edge 등 지원 브라우저에서만 동작합니다. 미지원 브라우저에서는 [백업 내려받기 (JSON)]으로 백업하세요.
- 파일 접근 API는 보안 컨텍스트가 필요하므로 `https://` 호스팅이나 `http://localhost` 에서 여는 것을 권장합니다.
  (예: `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속)
